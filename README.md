# Seven Seas Spa

A website for **Seven Seas Spa**, a fictional spa, built as a practice project for a Full Stack course.

The spa, its services and its contact details are made up. This is not a real business.

## Built with

- HTML5
- [Bootstrap 5.3](https://getbootstrap.com/) for layout and the responsive navbar
- [Font Awesome](https://fontawesome.com/) for icons
- Custom CSS in `assets/css/styles.css`
